🎮 XO Game – Tic Tac Toe Battle Arena

Challenge your mind with a modern and interactive version of the classic Tic Tac Toe game. This fast-paced strategy game is designed with a clean UI, smooth gameplay, and responsive controls to deliver an engaging experience on both desktop and mobile devices.

Whether you're playing against a friend or testing your tactical skills, every move matters. The game features real-time turn switching, winning pattern detection, score tracking, and an immersive gaming interface that keeps players entertained for hours.

Built using modern web technologies, this project demonstrates strong frontend development skills, responsive design principles, and interactive game logic implementation. It combines simplicity with strategic thinking, making it perfect for casual fun, quick challenges, and competitive gameplay.

✨ Key Features:

Interactive and responsive game board
Smooth user experience across devices
Real-time win/draw detection
Clean and modern UI design
Fun multiplayer gameplay experience
Lightweight and fast performance
